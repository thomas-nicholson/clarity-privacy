# Clarity privacy policy

This public repository hosts the privacy policy for the Android app **Clarity** (`com.thom.clarity`).

Public policy URL after GitHub Pages deployment:

- <https://thomas-nicholson.github.io/clarity-privacy/>

## Updating the policy

1. Update `index.html` so it remains consistent with the in-app policy and current data practices.
2. Commit and push to `main`.
3. Wait for GitHub Pages deployment and verify the public URL without authentication.
4. Update the mirrored release evidence in the private Clarity repository when behaviour or wording changes.

The repository is intentionally public so the policy does not depend on a privately operated app server or agent host.
